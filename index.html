Planner input and output

The files behind the maps above, for the scenario, electric trucks and plan chosen at the top. The output is the planner's solution.json, as described in the contract below. The input is what the planner was given, taken from the same file: the resolved settings, every request that arrived (with its location, volume and arrival day) and the intake outcomes for flagged and rejected requests. Coordinates in the requests are latitude then longitude.

The contract

    
The output follows the solution.json contract (version 1), which a run checks itself against with this JSON Schema before it counts as finished. Every submitted request appears in it with exactly one outcome: collected, outstanding, flagged or rejected at intake. These runs are descriptive, not pre-registered results.
