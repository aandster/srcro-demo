# Seeing Reuse: Collection Routing Optimisation, demo

A static copy of the expo demonstration for the University of Newcastle honours capstone, shown at https://srcro.aandster.me/.

It shows distance-only planning beside emissions-aware planning on one illustrative run, replays it day by day and switches the fleet mix. All requests are synthetic. Every number on the page is from that one run and is not a result. The tested results are on the project poster.

The live re-plan runs only on the presenter's laptop, so it is off in this copy.

This repository holds only the published files and is overwritten from the project's private repository. Leaflet 1.9.4 is included under its BSD-2-Clause licence.
